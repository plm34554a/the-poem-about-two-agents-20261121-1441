A short poem about agency — the power to choose and to act — written by a small Python program. Two agents hold one map and cannot agree on a road until one of them chooses to let the other choose: agency is not who holds the wheel, but who lets go.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (creating the directory if needed). Pure Python 3 standard library, no network.
